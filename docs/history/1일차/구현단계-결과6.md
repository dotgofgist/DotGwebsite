**구현 내용**
- 관리자 목록/상세 query는 실제 Supabase를 조회하고, 모든 함수 시작에서 `requireContentManager()` 재검사
- 공개 query는 `is_current = true` + `publication_status = published`만 반환
- 생성/수정은 `create_recruitment`, `save_recruitment` RPC로 모집 정보와 절차를 원자 저장
- 절차 수정 시 기존 `recruitment_steps` 전체 교체
- `created_by`, `updated_by`는 `auth.uid()` 기반 기록
- 처음 `published` 전환 시 `published_at` 설정
- current 지정/해제는 RPC로 처리, 기존 current 해제 후 새 current 지정
- archived 모집은 current 지정 차단
- 영구 삭제는 구현하지 않았고, archive는 `publication_status = archived` + `is_current = false`
- 제목, 요약, 상태, 공개 상태, 목록 필드, 일정, 지원 URL, 절차, 문의 URL 서버 검증 추가
- 위험 URL protocol은 `http/https` 외 차단
