## 5. Supabase 구조

- `env.ts`: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` 접근 계층. import 시 throw하지 않고, `requireSupabasePublicEnv()` 호출 시에만 오류 발생
- `client.ts`: 브라우저용 `createBrowserSupabaseClient()`, 호출 시에만 env 검사
- `server.ts`: 서버용 `createServerSupabaseClient()`, Next `cookies()`와 `createServerClient` 사용
- `proxy.ts`: env가 없으면 `NextResponse.next()`만 반환. env가 있으면 세션 쿠키 갱신 준비
- `database.types.ts`: 실제 스키마 없는 placeholder 타입
- `src/proxy.ts`: Next 16 Proxy convention 사용, 정적 자산 제외 matcher 설정

현재 redirect, Route 보호, 인증 검사는 구현하지 않았습니다.
