## 6. 접근성

- 각 페이지 최상위 `<h1>`은 하나만 유지했습니다.
- 콘텐츠 영역은 논리적인 `<section>`으로 구성했습니다.
- 실제 URL 없는 SNS는 가짜 링크로 만들지 않았습니다.
- 외부 링크가 생길 경우 `target="_blank"`와 `rel="noreferrer noopener"`가 적용되도록 구현했습니다.
- 장식용 Hero 그래픽과 이니셜 요소에는 `aria-hidden`을 적용했습니다.
- 기존 전역 `focus-visible` 스타일을 유지했습니다.
