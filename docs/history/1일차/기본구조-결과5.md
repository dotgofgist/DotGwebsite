## 4. 공지사항 데이터 구조

- `Notice`: slug, title, summary, plain text content, pinned, publishedAt, updatedAt
- mock data: 4개
- 고정 공지: 1개
- 정렬 규칙: 고정 공지 우선, 그다음 최신 발행일
- 최신 공지: `getLatestNotices(3)`로 발행일 기준 조회

## 5. 모집 데이터 구조

- `Recruitment`: 모집 제목, 요약, 상태, 대상, 자격, 활동, 일정, 절차, 지원 링크, 연락처
- `RecruitmentStatus`: `upcoming`, `open`, `closed`, `always`
- 현재 상태: `upcoming`
- 일정: 아직 없음
- 지원 링크: 아직 없음, 가짜 링크 생성하지 않음
- 연락처: 아직 없음, 연락처/공지사항 페이지로 안내

## 6. 구현 결과

- `/notices`: 공지사항 목록 표시
- `/notices/[slug]`: 공지 상세 표시
- 없는 공지 slug: 404 처리
- 공지별 metadata와 `generateStaticParams` 구현
- `/recruitment`: 모집 상태, 대상, 자격, 활동, 일정, 절차, 문의 안내 표시
- 지원 버튼은 URL이 없고 모집 예정 상태라 비활성 처리
- 홈 최신 공지는 notice mock data와 연결
- 홈 모집 CTA는 recruitment mock data와 연결
- 모바일 1열, 넓은 화면 그리드 배치로 구성

## 8. 접근성

- 공지 목록은 `<ul>`/`<li>` 구조 사용
- 공지 상세 제목은 `<h1>`
- 날짜는 `<time dateTime>` 사용
- 고정 공지는 `고정` 텍스트 배지로 표시
- 모집 절차는 순서가 있는 `<ol>` 사용
- 비활성 지원 버튼에는 이유 설명 제공
- 외부 링크가 생길 경우 보안 속성 적용되도록 구현
- 기존 `focus-visible` 스타일 유지
