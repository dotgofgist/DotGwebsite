# 기본구조 작업 결과 요약

## 작업 범위

게임창작부 동아리 웹사이트 DotG의 P0 기반을 만들기 위해 Next.js App Router 구조, 공개 사이트, 관리자 UI, mock data 기반 콘텐츠, Supabase 연결 준비까지 단계적으로 구현했습니다.

이번 기본구조 작업에서는 실제 Supabase DB 조회, 인증, CRUD, Storage 업로드, 운영 배포는 구현하지 않았습니다.

## 기술 스택 확인

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS 4
- pnpm
- Supabase 연결 준비
- Vercel 배포 예정

## Supabase 연결 준비

Supabase 실제 기능은 아직 연결하지 않았고, 이후 연결을 위한 안전한 기반만 준비했습니다.

설치한 패키지:

- `@supabase/ssr`
- `@supabase/supabase-js`

추가한 구조:

- `src/lib/supabase/env.ts`
- `src/lib/supabase/client.ts`
- `src/lib/supabase/server.ts`
- `src/lib/supabase/proxy.ts`
- `src/lib/supabase/database.types.ts`
- `src/proxy.ts`

환경 변수는 다음 두 개만 사용합니다.

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=
```

환경 변수가 없어도 import, lint, build가 실패하지 않도록 구성했습니다. 실제 Supabase query는 아직 작성하지 않았습니다.

## 데이터 접근 경계

현재 데이터 흐름은 다음 원칙으로 정리했습니다.

```text
페이지 또는 상위 Server Component → queries.ts → mock-data.ts
UI 컴포넌트 → props
```

기능별 query 파일:

- `src/features/projects/queries.ts`
- `src/features/notices/queries.ts`
- `src/features/recruitment/queries.ts`

각 query 파일에는 향후 Supabase 조회로 교체하기 위한 TODO를 남겼습니다.

## 검증 결과

각 단계에서 다음 명령을 반복 실행해 통과를 확인했습니다.

```powershell
pnpm.cmd lint
pnpm.cmd build
pnpm.cmd exec tsc --noEmit
```

최종 확인 기준:

- ESLint 오류 없음
- TypeScript 오류 없음
- production build 성공
- 환경 변수 없이 build 성공
- Supabase Proxy 추가 후 주요 공개/관리자 경로 정상 응답
