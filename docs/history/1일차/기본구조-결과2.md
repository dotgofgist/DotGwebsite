## 3. 구현 내용

공개 사이트 레이아웃에 Header, Footer, `main#main-content`, 본문 바로가기 skip link를 연결했습니다.

Header는 `DotG` 로고 링크, 데스크톱 내비게이션, 모바일 메뉴 버튼을 포함합니다. 메뉴 항목은 `publicNavigation` 설정을 재사용하고, `/projects/example`에서는 `/projects`, `/notices/example`에서는 `/notices`가 활성화되도록 공통 `isNavigationItemActive` 유틸을 만들었습니다.

모바일 메뉴는 햄버거 버튼으로 열고 닫히며, 메뉴 선택 시 닫힙니다. Escape 키 닫기와 `aria-expanded`, `aria-controls`, `aria-current`를 적용했습니다. 경로 변경 시에는 effect 안에서 강제로 setState하지 않고 `pathname` key remount로 닫히게 처리했습니다.

Footer는 사이트 설명, 빠른 링크, 관리자 로그인 링크, 현재 연도 저작권을 포함합니다.

## 4. Client Component

Client Component:

- `src/components/layout/mobile-menu.tsx`

이유:

- 모바일 메뉴 열림 상태 관리
- 현재 경로 확인
- Escape 키 이벤트 처리
- 현재 경로 기반 활성 메뉴 표시

`PublicHeader`, `PublicFooter`, `(public)/layout.tsx`는 Server Component로 유지했습니다.

## 5. 접근성

적용한 항목:

- `<header>`, `<nav>`, `<footer>`, `<main>` 시맨틱 구조
- 데스크톱 `nav aria-label="주요 메뉴"`
- 모바일 `nav aria-label="모바일 주요 메뉴"`
- 모바일 버튼 `aria-label`, `aria-expanded`, `aria-controls`
- 활성 링크 `aria-current="page"`
- focus-visible 유지
- `본문 바로가기` skip link 추가
- 로고 링크 accessible name 적용
