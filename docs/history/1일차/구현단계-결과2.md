**1. 작업 전 상태**
- `database.types.ts`: 실제 생성 타입 아님, `Tables: Record<string, never>` placeholder 상태.
- 로컬 Supabase: Docker daemon/pipe 없음으로 실행 불가.
- 환경 변수: 값은 출력하지 않았고, 코드상 미설정 fallback 경로 기준으로 검증.
- 기존 공개 query: `queries.ts`가 sync mock data 반환.
- 기존 관리자 query: 공개 `queries.ts`를 공유하고 있었음.
- 기존 검증: `pnpm lint` 성공, `pnpm build` 성공. 병렬 `tsc`는 `.next/types` 생성 타이밍으로 실패했지만 이후 순차 실행 성공.

**2. 데이터 소스 정책**
- Supabase 미설정: 기존 mock/config fallback 사용.
- Supabase 설정: 현재는 실제 DB 타입이 없으므로 명확한 오류를 throw.
- Supabase 조회 실패: mock으로 조용히 fallback하지 않도록 막아둠.
- 실제 `.from("projects")` 전환은 생성 타입 부재 때문에 하지 않았습니다. `any`/가짜 DB 타입 우회를 피했습니다.

**5-9. 조회/Mapper 상태**
- 프로젝트/공지/모집 query는 async 형태로 전환했고, 미설정 환경에서는 기존 정렬/데이터 유지.
- 관리자 화면은 mock query 유지.
- 실제 Supabase 목록/상세/관계 조회와 mapper는 아직 미구현입니다. 이유는 실제 생성된 Database 타입이 없고 Docker 문제로 타입 생성도 불가했기 때문입니다.
- thumbnail, relation sorting, nullable DB row 처리는 실제 타입 생성 후 구현해야 합니다.

**10. 관리자 회귀**
- 관리자 대시보드/프로젝트/공지/모집 페이지는 `admin-queries.ts` 기반 mock data 유지.
- Auth, CRUD, 저장/삭제 동작은 추가하지 않았습니다.

**11. Loading/Error**
- 프로젝트/공지/모집 route loading UI 추가.
- 프로젝트/공지/모집 route error boundary 추가.
