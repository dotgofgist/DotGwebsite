## 4. 관리자 레이아웃

- Header: 관리자 영역 표시, 공개 사이트 보기 링크, 비활성 로그아웃 UI
- Sidebar: `adminNavigation` 재사용, 현재 경로 활성 표시, 공개 사이트 보기 링크
- 모바일 메뉴: 열기/닫기, Escape 닫기, 경로 변경 시 닫힘
- `/admin/login`은 대시보드 레이아웃 밖에 있어 Sidebar/Header가 표시되지 않습니다.
- `/admin` 하위 경로에는 관리자 Header와 Sidebar가 적용됩니다.

## 5. 관리자 기능 UI

- 대시보드: 프로젝트 수, 공지 수, 고정 공지 수, 모집 상태, 최근 콘텐츠
- 프로젝트 관리: mock 프로젝트 목록, 수정 링크, 공개 보기, 삭제 확인 UI
- 프로젝트 생성/수정: 동일한 `ProjectForm` 재사용
- 공지사항 관리: mock 공지 목록, 고정 표시, 수정 링크, 공개 보기, 삭제 확인 UI
- 공지사항 생성/수정: 동일한 `NoticeForm` 재사용
- 모집 관리: 현재 모집 데이터 기반 `RecruitmentForm`
- 사이트 설정: `siteConfig`, `contactItems`, `socialLinks` 기반 폼
- 삭제 확인 UI: 실제 삭제 없이 “DB 연결 후 활성화” 안내
