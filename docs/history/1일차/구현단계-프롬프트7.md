# 4. 권한 정책

설정 관리 권한은 다음 역할에만 허용한다.

```text
editor
admin
```

다음 역할에는 허용하지 않는다.

```text
anon
authenticated member
```

권한 검사는 다음 계층에 모두 적용한다.

```text
관리자 Dashboard Layout
→ 관리자 페이지 접근 보호

설정 query와 Server Action
→ 서버 함수 호출 시 권한 재검사

Supabase RLS
→ 실제 SELECT·INSERT·UPDATE·DELETE 강제
```

관리자 Layout을 통과했다는 이유만으로 Action 권한 검사를 생략하지 마라.

Service Role Key로 RLS를 우회하지 마라.

```text
→ undefined
```

```text

→ config 기본값

DB 조회 실패
→ 오류
```

# 16. UUID 검증

다음 함수와 Action에서 UUID를 검증한다.

```text
getAdminContactItemById
getAdminSocialLinkById
updateContactItemAction
deleteContactItemAction
updateSocialLinkAction
deleteSocialLinkAction
```

유효하지 않은 UUID:

* DB query를 수행하지 않음
* 수정 페이지에서 `notFound()` 또는 관리자 오류 UI

# 69. config fallback 유지

다음 파일은 삭제하지 않는다.

```text
src/config/site.ts
src/config/contact.ts
src/config/social.ts
```

역할:

```text
Supabase 환경 변수 미설정
→ config fallback

Supabase 설정 + 조회 성공
→ DB 데이터

Supabase 설정 + 조회 실패
→ 오류
```

Supabase 조회 실패를 config fallback으로 숨기지 마라.

DB row가 없는 경우에만 기능별 기본값 사용 여부를 명확하게 결정한다.

# 90. 최종 완료 기준

다음 조건을 모두 만족하면 이번 작업을 완료한 것으로 본다.

* 관리자 사이트 설정이 실제 Supabase 데이터를 사용한다.
* 관리자 연락처 목록이 실제 Supabase 데이터를 사용한다.
* 관리자 SNS 목록이 실제 Supabase 데이터를 사용한다.
* 사이트 기본 정보가 singleton row에 저장된다.
* singleton row가 없어도 관리자 저장으로 생성된다.
* 사이트 설정 입력이 서버에서 검증된다.
* 연락처 생성·수정·삭제가 실제 DB에서 동작한다.
* SNS 생성·수정·삭제가 실제 DB에서 동작한다.
* 연락처와 SNS 활성 상태를 관리할 수 있다.
* 연락처와 SNS 정렬 순서를 관리할 수 있다.
* 위험한 URL protocol이 차단된다.
* URL 없는 SNS를 활성화할 수 없다.
* 모든 query와 mutation에서 관리자 권한을 재검사한다.
* anon과 member는 설정을 수정할 수 없다.
* editor와 admin은 설정을 관리할 수 있다.
* Service Role Key를 사용하지 않는다.
* 공개 페이지는 활성 연락처만 표시한다.
* 공개 페이지는 활성 상태이며 URL이 있는 SNS만 표시한다.
* 비활성 항목은 관리자 목록에는 유지된다.
* 연락처·SNS 삭제는 영구 삭제임이 명확하게 표시된다.
* 공개에서만 숨기려면 비활성화를 사용할 수 있다.
* 사이트 설정 변경이 필요한 공개 페이지에 반영된다.
* 연락처 변경이 `/contact`에 반영된다.
* SNS 변경이 메인·연락처의 SNS 영역에 반영된다.
* 기존 config 파일은 Supabase 미설정 fallback으로 유지된다.
* Supabase 설정 후 조회 오류가 config fallback으로 숨겨지지 않는다.
* Storage와 이미지 업로드는 구현하지 않는다.
* 사용자 역할 관리는 구현하지 않는다.
* 실제 Secret이나 사용자 정보가 코드 또는 Git diff에 없다.
* 모바일과 접근성에 회귀가 없다.
* `pnpm lint`, `pnpm build`, `pnpm exec tsc --noEmit`이 통과한다.
