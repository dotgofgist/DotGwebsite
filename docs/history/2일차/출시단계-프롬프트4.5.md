현재 DotG는 GitHub Actions preview.yml과 production.yml이 Vercel CLI 배포를 직접 담당한다.
Vercel Git Integration에 의한 자동 Preview/Production 배포와 중복되지 않도록 dotg-web/vercel.json에 git.deploymentEnabled: false를 추가하라.
기존 Root Directory가 dotg-web이므로 파일 위치도 해당 앱 루트로 둔다.
다른 Vercel 설정은 추가하지 말고, JSON 유효성·build·lint를 검증한 뒤 diff를 보고하라.
