**주요 변경**
- `@playwright/test` 설치 및 `playwright.config.ts` 추가
- `scripts/e2e-web-server.mts` 추가: Windows/PowerShell 친화적으로 Next dev server 실행, local Supabase anon key 자동 주입
- `tests/e2e/` 추가:
  - global setup: local Supabase 안전 검사, E2E 계정 준비, 세션 storage state 생성
  - global teardown: `e2e-*` 콘텐츠와 `tests/e2e/.auth` 정리
  - public smoke: `/`, `/about`, `/projects`, 상세, `/recruitment`, `/notices`, 상세, `/contact`, not-found 화면
  - auth/authorization: anon redirect, unsafe `next` 방어, logout 후 차단, member/editor/admin route 접근 행렬
  - admin CRUD: editor로 프로젝트/공지 생성·수정 후 Supabase DB row 확인
- `docs/e2e-testing.md`, `README.md`, `.env.example`, `.gitignore` 갱신
- local E2E fixture가 service role로 계정/fixture를 준비할 수 있도록 migration grant 추가 및 migration 목록 테스트 갱신
